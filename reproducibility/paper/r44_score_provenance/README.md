# R4.4 per-image score provenance archive

This directory contains only per-image evidence that can be traced to an existing prediction/evaluation artifact. It does not manufacture image-level observations from aggregate table entries.

## Provenance classes

- **A — author experiment.** HazeGroupNet (HGN-T/S/L) values are author-confirmed run-level aggregates. No separate HGN per-image package is asserted or included here.
- **R — recomputed.** Scores were recomputed with the frozen evaluator from retained predictions, or, for DCP, from deterministic outputs generated by the algorithm. The corresponding per-image CSVs are included below.
- **T — transcribed aggregate.** A compatible per-image package was not available for the transcribed comparison rows (including RSDformer, SFAN, PhDnet, MCAF-Net and DFFNet). No synthetic or reconstructed per-image CSV is supplied for these rows.

The single-method files use the schema `image_id,haze_level,psnr,ssim_gaussian11,deltaE00`; the method is unambiguously encoded in the filename. The three public-eight files additionally include `method_key,method_label`. All hashes are SHA-256 over the exact archived bytes.

## Integrity checks

- Every archived single-method file has the expected 304 RRSHID rows or 135 SateHaze1k rows, no empty required metric, and no duplicate `(image_id,haze_level)` key.
- Each public-eight file has exactly eight methods. RRSHID has 304 rows per method; each SateHaze1k protocol has 135 rows per method (45 thin, 45 moderate and 45 thick images per method).
- The three standardized public-eight files have no empty required field and no duplicate `(method_key,image_id,haze_level)` key.
- HGN aggregate values and T-class aggregate values are intentionally outside the per-image archive scope; their absence must not be interpreted as a generated zero-row package.
